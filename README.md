# Podium (working name)

An iPod redesigned as a modern music operating system — the classic wheel-and-menu interaction model, a restrained Liquid Glass-inspired material language, and a modern music player underneath.

**Status:** pre-implementation. Phases 0–2 (audit, product/UX specification, architecture) are complete; the design benchmark (vertical slice) is next. No application code exists yet.

- Platform: native Android (Kotlin, Jetpack Compose, Media3) — minSdk 29, targetSdk 36.
- Music sources at launch: music on the device, OpenSubsonic-compatible servers (Navidrome, Gonic, …), and Audius. Podium does not circumvent any service's access controls.
